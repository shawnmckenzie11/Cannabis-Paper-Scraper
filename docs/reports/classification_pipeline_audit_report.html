Executive Summary

This audit examines the Cannabis Paper Scraper classification pipeline: a node-based literature system that harvests PubMed records, routes them through Maude (deterministic) and LLM-assisted classifiers, and improves accuracy through controlled RL cycles. The decision tree runs Node 0 (relevance gate), Node 1B/1A (secondary literature before original research), and Node 2A/2B/2C (clinical, in vivo, in vitro extraction).

As of 28 June 2026, eleven golden-endpoint cycles completed with guard validation passed. Batch alignment ranges from 90.0% to 100.0% (mean 92.2%) against a ≥90% guard threshold. Golden row 0 (node2c.cell_culture_other_in_vitro.cannabinoids_dissolved_in_media) reached 100% alignment after three guard iterations, with subnode reingest changing 3,162 of 3,778 papers and cohort routing improving by +78 within a 1,420-paper pool. Six node2b endpoints passed guard at 90.0–92.2% alignment. Quality gates, build traceability, and artifact logging are in place; 67 of 78 golden-table rows remain uncycled.

Architecture Overview

The design specification defines five principles: Maude for cheap deterministic extraction; LLM and PDF tier for ambiguity; sub-threshold records to expert review; locked expert corrections; and same-holdout re-measurement after every deploy. Each record stores classification source, version/build ID, confidence, and timestamp. Production writes target Fly Postgres; the active build is MAUDE_CLASSIFIER_BUILD_ID = "20260628-manual-edit-tracker-v2" in calibration_build.py.

Learning Loops

Loop A (subnode calibration). PDF Maude A/B on Fly → feedback → patch (extractor.py, maude_classifier.py, maude_cues.json) → build bump → deploy → same-holdout refresh → subnode reingest and blast-radius via run_loop_a_finish.sh.

Loop B (golden endpoint RL). Per golden-table row (78 total, largest pool first): pull candidates → LLM-label 10 → promote top 5 → Claude patch feedback → golden guard (≥90%, max 10 iterations) → reingest → push deltas. Row n is blocked until prior rows show guard_passed: true.

Manual edit cycle. manual_edit_cycle.py harvests expert-drawer edits from feedback_audit, deduplicates by paper/field, and routes them into the Loop A feedback pipeline between scheduled batches. Current build ID reflects this track (20260628-manual-edit-tracker-v2).

Quality Assurance & Metrics

  • Golden guard. Pass gate: average batch alignment ≥90% on promoted golden papers (GOLDEN_MIN_ALIGNMENT_PCT). Among eleven completed endpoints in golden_endpoint_status.json, all eleven report guard_passed: true (100% guard pass rate on completed cycles). Guard iterations ranged from 1 to 6 per endpoint.
  • Blast radius. After reingest, patch_blast_radius.py quantifies how many papers and fields changed under a patch. For row 0 (node2c other in vitro / dissolved media): 3,778 papers scanned, 3,162 changed (83.7%), 7,142 total field-level changes across 21 of 28 tracked characteristics. Top affected fields included classifier_version (2,349), summary (857), and outcome_domain (825).
  • Cohort validation. similarity_cohort_validation.py measures routing impact on papers similar to the endpoint cohort. Row 0 cohort pool: 1,420 papers; routing matches rose from 1,279 to 1,357 (+78); 996 cohort papers had routing changes; 1,295 subnode papers had routing changes.
  • Feedback_audit upward propagation. At classification time, prior expert corrections are retrieved via BM25 search over feedback_audit_fts and injected as dynamic few-shot context—distinct from static cues in rules_config.json. Loop A finish and golden cycles preflight-sync Postgres feedback_audit into local SQLite before reingest so patches respect locked expert fields.

Limitations & Safeguards

Limitations: small holdout batches (five promoted papers per cycle) limit power on rare fields; 67 of 78 golden rows remain uncycled; subnode reingest can change most papers in scope (row 0: 83.7%). Safeguards: Fly build-ID preflight, golden guard (≤10 iterations), row gating, expert field locking, zero-regression gate, full artifact logging, and per-record traceability. No credentials appear in this report.

Conclusion

The pipeline provides auditable separation of routing, extraction, expert review, and rule refinement. Completed cycles show repeatable guard passage at ≥90% alignment; row 0 reached 100% with measurable cohort routing gain. Blast-radius and cohort validation expose production impact before push. Next priorities: sequential golden-table completion, Loop A calibration for out-of-scope field drift, and blast-radius review when change rates exceed tolerance.
